# Сплиттер кадров из MP4 в WebP

Инструмент для извлечения кадров из видеофайлов MP4 и сохранения их в формате WebP.

## Использование

### Базовое использование

```bash
python frame_splitter.py video.mp4
```

Это извлечет все кадры из видео и сохранит их в папку `frames/` с именами `frame_000000.webp`, `frame_000001.webp` и т.д.

### Параметры командной строки

- `video` - Путь к видео файлу MP4 (обязательный параметр)
- `-o, --output` - Директория для сохранения кадров (по умолчанию: `frames`)
- `-q, --quality` - Качество WebP от 1 до 100 (по умолчанию: 80)
- `-s, --step` - Шаг извлечения кадров (1 = каждый кадр, 2 = каждый второй и т.д., по умолчанию: 1)
- `-p, --prefix` - Префикс для имен файлов (по умолчанию: `frame`)

### Примеры

Извлечение всех кадров с высоким качеством:
```bash
python frame_splitter.py video.mp4 -q 95
```

Извлечение каждого 30-го кадра (для уменьшения количества файлов):
```bash
python frame_splitter.py video.mp4 -s 30
```

Сохранение в другую папку с другим префиксом:
```bash
python frame_splitter.py video.mp4 -o output_frames -p img
```

Комбинированный пример:
```bash
python frame_splitter.py video.mp4 -o frames -q 90 -s 10 --prefix frame
```
